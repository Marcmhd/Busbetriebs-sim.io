# Krefrath Transit Roleplay - OMSI 2 Busbetrieb

Dies ist die offizielle Website für den fiktiven OMSI 2 Rollplay-Busbetrieb **Krefrath Transit**. 

## Projektbeschreibung

Diese Website dient als zentrale Plattform für unseren virtuellen Busbetrieb im OMSI 2 Simulator. Hier können sich Mitglieder registrieren, auf den Fuhrpark zugreifen und Informationen zu unseren Linien und Maps erhalten.

### Funktionen

- Registrierung neuer Mitglieder mit Bewerbungsformular
- Übersicht über den Fuhrpark mit verschiedenen Bustypen
- Darstellung der Linien und Maps, z.B. Krefrath, Städtedreieck V3, Rheinhausen, Dél-Pest (Budapest), Aachen
- Interaktive Map-Auswahl mit Details zu Linien und Haltestellen
- Responsive Design für Desktop und mobile Geräte

## Installation und Nutzung

Da es sich um eine statische Website handelt, kann sie lokal im Browser geöffnet oder auf einem Webserver (z.B. GitHub Pages, Netlify) gehostet werden.

### Lokales Testen

1. Repository klonen oder Dateien herunterladen
2. `index.html` im Browser öffnen
